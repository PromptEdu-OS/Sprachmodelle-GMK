Gemini Canvas-Modus: Physik visuell begreifen

Sprachmodelle sind extrem stark im Schreiben von Programmiercode. Statt trockener Theorie lassen wir uns im Canvas-Modus eine interaktive Simulation für das 2. Newtonsche Gesetz programmieren:

Die physikalische Grundformel einfach erklärt:
F = m · a
umgestellt nach der Beschleunigung:
a = FAntrieb − FReibung m (Masse)

Was bedeutet das? Je größer die Masse m (steht unten im Bruch!), desto kleiner ist die Beschleunigung a bei gleicher Kraft. Ein schwerer Block kommt also viel langsamer in Fahrt!

Schnell-Vergleich für die Live-Vorführung:
Antriebskraft F (Schiebekraft): 600 N
Masse m des Objekts (Gewicht): 200 kg
Reibungskraft FR (Bodenreibung): 50 N

Netto-Kraft (F − FR)
550 N
Beschleunigung (a = F / m)
2.75 m/s²

// Von Google Gemini im Canvas-Modus generierter Simulations-Code:
function berechneBeschleunigung(antriebsKraft, reibungsKraft, masseKg) {
  const nettoKraft = Math.max(0, antriebsKraft - reibungsKraft);
  // 2. Newtonsches Gesetz: F = m * a  -->  a = F / m
  const beschleunigung = nettoKraft / masseKg;
  return {
    nettoKraft: nettoKraft + " N",
    beschleunigung: beschleunigung.toFixed(2) + " m/s²"
  };
}
